> English version: [VIDEO_SCRIPT.md](VIDEO_SCRIPT.md)

`scripts/demo/record.mjs`（Playwright + DevTools スクリーンキャスト）で、2026-11-12 の本番クロールデータを使って自動録画した。ナレーションは画面の字幕と同じ英文を音声合成（Kokoro TTS、声 `am_michael`）したもので、各字幕は読み終わるまで次に進まない。

PayPal の場面は、実際のサンドボックス入金4件（$142.30、$48.00、$27.00、$19.50 — バッチ `VDW23CN4GHX8Y`）を `PAYPAL_FIXTURE` で再生しているため、Transaction Search の反映遅延に左右されない。録画環境には Claude API キーがなかったので、動画の入金照合はキーワードによる予備ルールで行っている。本番サイトでは Claude が照合する。
